> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Patch `extension/backend/core/llm/schema_probe.py` so it (a) loads `.env`, (b) cleanly separates schema-conformance failures (`json_failed`) from infrastructure failures (`transport_error`), (c) fails loudly on silent runtime model fallback, (d) varies seed per trial, (e) captures truncated raw output on JSON failures, (f) writes a reproducibility manifest with hard git provenance; then execute the 18-cell × 5-trial real run and commit the artifact.

**Architecture:** TDD cycle per behavior. One file (`schema_probe.py`) + one test file (`tests/test_llm_schema_probe.py`). 12 TDD tasks (Commit 1) + 3 manual execution tasks (pre-flight, full run, Commit 2). No changes to `base.py`, `gemini.py`, `ollama.py`, or registry.

**Tech Stack:** Python 3.12, pytest, pydantic v2, python-dotenv, importlib.metadata, subprocess (git CLI). All dependencies already in `requirements.lock`.
