# Legacy Intermediate Pipeline Artifacts

This directory contains 227 intermediate JSON files produced by the multi-agent
pipeline (Scout / Architect / Specialist / Verifier / Refiner / Synthesizer stages)
during development sessions **prior to the WP-01b RunManifest schema** (introduced
2026-05-19). These files were generated by `_save_intermediate(...)` calls in
`core/architect.py` and reflect experiment runs that predate the formal paper-data
recording infrastructure (`PaperRunManifest`, `JudgeVerdict`, `AggregatedConfiguration`).

They are archived here for historical traceability but will **not** be reused in the
EMSE submission pipeline. New pipeline runs continue to write fresh intermediate
JSONs into `core/intermediate/` as before; those live files are gitignored and
regenerated on demand. The present archive is kept under version control solely to
preserve the git history of early development iterations.
